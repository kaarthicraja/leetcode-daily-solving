# LeetCode Daily Solving

My solved LeetCode problems, organized by folder, each with a solution
and a short write-up.

- `day-NNN-<slug>/` — LeetCode's Daily Challenge for that date.
- `regular-leet-code-programs/<number>-<slug>/` — other problems solved
  outside the daily challenge.

## Layout

```
day-NNN-<slug>/
├── README.md       # problem summary, approach, complexity, key learnings
└── solution.py      # the solution, in LeetCode's own class Solution format

regular-leet-code-programs/<number>-<slug>/
├── README.md       # title, difficulty, LeetCode link
└── solution.py      # the solution, in LeetCode's own class Solution format
```
