# LeetCode Daily Solving

My daily solved LeetCode problems — one folder per day, each with a
tested, reviewed solution and a short write-up.

Generated and committed automatically by my [DSA Daily
Agent](https://github.com/kaarthicraja/leetcode-daily), which each day:

1. Picks that day's real LeetCode **Daily Challenge**.
2. Solves it, generates and runs a test suite, and repairs failures
   automatically.
3. Reviews the passing solution and writes it up here.

I always submit the solution on leetcode.com myself, by hand — nothing
in that automation ever touches login, CAPTCHA, or the Submit button.

## Layout

```
day-NNN-<slug>/
├── README.md       # problem summary, approach, complexity, key learnings
└── solution.py      # the solution, in LeetCode's own class Solution format
```
